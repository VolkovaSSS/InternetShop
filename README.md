# **Проект интернет-магазина**
## Описание 
- Реализация ядра для интернет-магазина. В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.
- получает данные из файлов формата json
## Структура проекта
- main.py - реализована основная логика проекта
- src/category.py - описывает класс категории товаров
- src/product.py - описывает класс продукты (товары)
- src/lawngrass.py - описывает подкласс Трава газонная класса продукты (товары)
- src/utils - считывание json-файла с данными
- data - файлы с данными о транзакциях
- tests - папка с тестами

## Установка
- Клонируйте репозиторий:
```git clone git@github.com:VolkovaSSS/pythonProject1.git```
- Установите зависимости:
```pip install -r requirements.txt```
- создайте файл .env по шаблону .env.example
## Использование
Для использования нужно запустить файл main.py
например: python main.py
### Зависимости
- Python 3.x
- requests = ">=2.25.1"
- flask = ">=2.0.1"
## Тестирование
При тестировании использовался фреймворк pytest
Тестами охвачены модули:
- category
- product

Для запуска тестов выполните команду:
```sh
pytest --cov=src --cov-report=html
```
